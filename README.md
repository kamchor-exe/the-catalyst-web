# The Catalyst Web Co.

A responsive, single-page website for white-label optimization and QA services.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server and visit its local address.

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `index.html` and `script.js` with the business email address. The inquiry form validates required fields and opens a prefilled email in the visitor’s email app once the address is configured.
- The contact form has no backend. If you prefer direct web submissions, connect it to a form endpoint you control.
- The supplied brand image is saved as `brand-logo.png` and can be replaced with an updated logo file of the same name.
